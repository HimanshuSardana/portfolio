Features

Everything a blog needs.
Nothing it doesn't.

⚡

Blazing builds

Go-compiled Markdown rendering. Pages compile in single-digit milliseconds — the whole site before your finger leaves Enter.

📦

One binary, zero deps

go install and you're done. No Node, no bundler, no lockfile with 900 transitive packages.

🎨

Themes are just HTML

Two template files, standard Go html/template syntax. No new language to learn, nothing to eject from.

🔥

Live reload

kite serve watches content, themes and config, rebuilds and refreshes your browser automatically.

📡

RSS included

Every build regenerates feed.xml. Readers can subscribe with zero plugins or config.

📑

TOC as data

Headings are parsed into structured table-of-contents data — render a sidebar, a dropdown, or nothing at all.

Up and running in a minute

kite init scaffolds everything, then it's just Markdown files and kite build.

# install
go install github.com/HimanshuSardana/kite@latest
# scaffold + write
kite init && hx content/hello.md
# build + preview
kite build && kite serve  # → http://localhost:8000

FAQ

Questions, answered

Is kite free?

Yes — free and open source. The source is on GitHub, grab the binary with go install.

Why another static site generator?

Hugo is powerful but comes with its own templating world to learn; JS frameworks eat 100MB of RAM to render Markdown. Kite is the smallest tool that does the job: one binary, millisecond builds, themes in plain HTML. Read the full story in Why kite exists.

How fast is it, really?

Each page compiles in ~0–2ms. A personal blog builds before your finger leaves the Enter key — see the terminal above, that's real output.

Do I need Go installed to use my site?

Only to install kite itself (go install needs Go 1.25+). The output is plain static HTML — host it anywhere, no Go, no server logic.

Can I bring my own theme?

Yes — two HTML files (home.html + layout.html) with standard Go template syntax. This entire page is a custom kite theme. Guide: Building themes.

Does it do RSS, drafts, taxonomies?

RSS yes — feed.xml regenerates every build. Drafts and taxonomies: not yet. If you need those today, Hugo is the honest recommendation.
